## Objective
Refine the bottom option rows in the **Sender Details** section of the desktop checkout so the labels, supporting copy, checkboxes, and icons feel visually balanced and consistent.

## Scope
**Desktop checkout only.** These changes must not alter the mobile or tablet checkout layouts.

Apply the update to both options:
- Get order updates on WhatsApp
- Send this gift anonymously

## Required UI changes
1. **Tighten title-to-description spacing**
   - Reduce the vertical gap between each main option label and its supporting sentence to approximately **5 px**.
   - Treat the title and description as one compact two-line text block.
   - Keep the existing font family, font size, weight, colors, and wording unchanged.

2. **Vertically center the controls**
   - Vertically center the checkbox and adjacent icon against the complete two-line text block, including both the title and description.
   - Do not align the checkbox/icon only to the title line.
   - Apply the same alignment rule to the WhatsApp and anonymous-gift options.

3. **Preserve text alignment**
   - Keep the helper descriptions horizontally aligned consistently between both options.
   - Preserve the approved wording:
     - “We’ll send order and delivery updates to this number. Opt out anytime.”
     - “Your name won’t appear on the gift card or recipient notifications.”

4. **Preserve functionality**
   - WhatsApp updates remain selected by default.
   - “Send this gift anonymously” remains unselected by default.
   - Clicking each checkbox/option must continue to update its existing checkout value and behavior.
   - Do not change validation, checkout submission logic, analytics, or stored data.

## Do not change
- Mobile or tablet checkout styling
- Sender Details heading
- First name, Last name, Email address, or WhatsApp number fields
- Existing icons, colors, border styles, typography, copy, or input behavior
- Overall card width or desktop checkout column structure

## Acceptance criteria
- On desktop, both option titles sit approximately 5 px above their helper descriptions.
- The checkbox and icon in each option are vertically centered relative to its complete two-line text block.
- Both option rows use identical spacing and alignment rules.
- Helper text remains readable and does not wrap unexpectedly at supported desktop breakpoints.
- The desktop card does not gain unnecessary height or whitespace.
- No visual or behavioral regression appears on mobile/tablet.
- Both checkboxes retain their current default states and functionality.
- The implementation matches the attached approved mockup.

## QA
Test on the supported desktop breakpoints in Chrome and Safari. Verify checked and unchecked states for both controls, confirm keyboard focus and click targets still work, and run a quick regression check on mobile/tablet to confirm that no styles changed there.
