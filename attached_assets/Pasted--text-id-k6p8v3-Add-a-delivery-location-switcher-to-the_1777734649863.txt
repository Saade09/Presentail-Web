Add a delivery location switcher to the Home page header.

Goal:
Users should be able to switch the country and city they want to deliver to from the Home page header. The available countries and cities must come from Presentail OS, which is a separate Replit application.

Reference behavior:
Use the attached screenshots as the UX reference.

The flow should work like this:
1. Home page header shows the selected delivery city/country.
2. User taps the delivery selector.
3. A bottom sheet opens.
4. User can choose a country.
5. After selecting a country, user can choose a city for that country.
6. The selected city/country updates in the Home header.
7. The selected location persists after app restart.

Header UI:
Add a compact delivery selector in the Home page header.

Suggested header display:
- Label: “Deliver To” or “Delivery”
- Selected city: “Dubai”
- Small downward chevron

Example:
Deliver To
Dubai ˅

Requirements:
- Keep the header clean and not crowded.
- Header must remain sticky and visible while the user scrolls.
- The selected city/country should be visible from the Home page.
- Tapping the selector opens the delivery location bottom sheet.
- If there is not enough space, show a location pin icon + selected city.
- Keep the search icon working as before.
- Do not break the Home page hero, product sections, or bottom navigation.

Bottom sheet UX:
Create a polished bottom sheet/modal similar to the screenshots.

Bottom sheet style:
- White background
- Rounded top corners
- Dimmed background overlay
- Drag handle at the top
- Large elegant title
- Close X button
- Premium, clean spacing
- Dark teal text
- Selected value highlighted
- Smooth open/close animation

Step 1: Select Country
Bottom sheet title:
“Send your gift to...”

Section title:
“Select Country”

Show all active delivery countries from Presentail OS.

Each country row should include:
- Flag icon or emoji
- Country name
- Chevron arrow

Example countries shown in reference:
- Kuwait
- Saudi Arabia
- Oman
- Qatar
- Bahrain
- United Arab Emirates
- United Kingdom
- Jordan
- Egypt

Important:
Do not hardcode this final list inside the UI. Countries must come from Presentail OS or a single temporary fallback service/config while integration is being connected.

When user taps a country:
- Move to Step 2, Select City, for that country.

Step 2: Select City
Bottom sheet title:
“Send your gift to...”

Show selected country row:
- Flag
- Country name
- “Change Country” link on the right

Section title:
“Select City”

Show all active cities for the selected country.

Selected city:
- Highlight selected city in dark teal or brand accent.
- Show a checkmark icon beside the selected city.

When user selects a city:
- Save selected country and city locally.
- Close the bottom sheet.
- Update the Home header immediately.

Change Country behavior:
- Tapping “Change Country” returns to Step 1 country selection.
- Country and city selection should not break if user cancels midway.

Data source:
Countries and cities we deliver to are defined in Presentail OS.

Implementation requirements:
1. Inspect how the customer app currently fetches API data.
2. Inspect the Presentail OS Replit project if accessible.
3. Look for existing models, tables, endpoints, or admin data for:
   - countries
   - cities
   - delivery zones
   - delivery areas
   - supported regions
   - active markets
4. If Presentail OS already exposes an API endpoint, connect to it.
5. If Presentail OS does not yet expose an endpoint, create a clean service abstraction in the customer app and document the API contract needed.

Suggested API contract:
GET /api/delivery-locations

Expected response:
```json

        }

    }
  ]
}
````

Only show:

* active countries
* active cities

* selectedDeliveryCountryId

* whether user manually selected the location

Use AsyncStorage/local storage depending on the app setup.

First launch behavior:

* If saved location exists, use it.
* If no saved location exists, fetch delivery locations from Presentail OS.
* Try to auto-select based on IP/country if location detection already exists.
* If detected country is supported, select that country and the default/first active city.
* If detection fails or country is unsupported, default to Lebanon or the first active country/city returned by Presentail OS.
* Make the fallback default configurable in one place.

Manual selection:

* Manual selection should override auto-detection.
* Do not re-detect and overwrite the user’s selected city on every app launch.
