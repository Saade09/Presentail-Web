### 1. Optimize Google Fonts loading

Currently Inter is loaded from Google Fonts and is render-blocking.

Please replace this with a better approach.

Preferred solution:

* Self-host the Inter font locally inside the project.
* Use `@font-face` declarations.
* Use `font-display: swap`.
* Only include the font weights actually used in the app.
* Prefer modern formats such as `.woff2`.
* Remove the external Google Fonts stylesheet request entirely if possible.

Example direction:

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-400.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

Make sure the app still visually uses Inter everywhere.

If self-hosting is not practical immediately, then at minimum:

* Add `preconnect` for `https://fonts.googleapis.com`
* Add `preconnect` for `https://fonts.gstatic.com` with `crossorigin`
* Keep `display=swap`
* Make sure font loading does not block rendering unnecessarily

But the preferred final state is **no Google Fonts render-blocking request**.
