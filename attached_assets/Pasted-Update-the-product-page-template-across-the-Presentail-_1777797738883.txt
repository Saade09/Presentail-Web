## Reference page style

The product page should look identical in structure and feel to the current Presentail product page shown in the screenshot:

Product: **Rosé Whisper**

Key layout requirements:

1. **Header / navigation**

   * Keep the clean Presentail header layout.
   * Top navigation should include:

     * Occasions
     * Flowers & Plants
     * Gifts
     * Brands
   * Centered Presentail logo.
   * Right side should include:

     * About Us
     * Search icon
     * User/account icon or greeting
     * Cart icon
   * Header should be clean, white, spacious, and consistent across product pages.

2. **Breadcrumb**

   * Display breadcrumb above the product area.
   * Example:
     `Home > Hand Bouquets > Rosé Whisper`
   * Breadcrumb should be dynamic based on product category and product name.

3. **Main product layout**

   * Use a two-column desktop layout.
   * Left side: product image gallery.
   * Right side: product info and purchasing panel.
   * The page should have generous whitespace and match the proportions in the screenshot.

4. **Image gallery**

   * Show vertical thumbnails on the left.
   * Show the selected main product image large to the right of thumbnails.

   * Thumbnails should also be rounded rectangles.
   * Include a share icon overlay near the top-right of the main image.
   * Include an expand/fullscreen icon overlay near the bottom-right of the main image.
   * Images should be dynamic per product.

5. **Product information panel**

   * Price should appear below the title.

     `AED 260`

     `TAX Inclusive`

   * Currency should be dynamic by country if already supported.

6. **Points earned**

     `Earn 260 Points`

     `Presentail Points`

     `Delivery Options`

     `OR`

     `Select date and time of delivery`

Important: the layout should not be hardcoded for Rosé Whisper. Rosé Whisper is only the visual reference. The same template should work for all products.

## Responsiveness

Implement responsive behavior:

* Desktop:

  * Two-column layout exactly like the screenshot.
  * Thumbnail column + large image on the left.
  * Product info panel on the right.

* Tablet:

  * Maintain two columns if space allows.
  * Reduce image and spacing proportionally.

* Mobile:

  * Stack layout vertically.
  * Product images first.
  * Product info below.
  * Thumbnails can become horizontal below the main image.
  * Add to Cart button should remain full-width.
  * Benefits and payment rows should remain readable.

* Rounded image containers.

## Technical implementation requirements

Please inspect the current product page/template implementation and update the reusable product page component/template rather than only changing a single product page.

Do not hardcode values that should come from product data.

Create clean reusable components where appropriate, for example:

* `ProductGallery`
* `ProductInfo`
* `DeliveryOptions`
* `ProductBenefits`
* `PaymentMethods`
* `ProductTabs`

Use the existing project architecture, styling system, and data structures where possible.

If product data does not currently include some of these fields, add temporary fallback values while keeping the structure ready for dynamic data later.

For delivery time, create a placeholder dynamic variable or config-driven field, for example:

```js
deliveryTimeLabel = cityDeliveryConfig?.expressDeliveryTimeLabel || "Arrives in 90 minutes"
```

Do not permanently hardcode the 90-minute delivery time.
