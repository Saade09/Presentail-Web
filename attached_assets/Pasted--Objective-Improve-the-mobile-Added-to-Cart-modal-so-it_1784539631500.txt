
Objective
Improve the mobile “Added to Cart” modal so it feels cleaner, more reassuring, and easier to navigate while preserving the current product recommendation cards exactly as they are.

Approved UI changes
Success header
Replace the all-caps heading with: Added to your cart
Display the second line as: Cart total: $[current cart total]
Keep the close icon in the top-right corner.
Free-delivery progress area
Reduce the height and excess padding.
Use the dynamic message: You’re $[remaining amount] away from free standard delivery
Supporting copy: Express delivery is available for an additional fee.
Keep the existing orange progress bar and dynamic current-cart/goal values.
Use a simple teal delivery-truck icon without the large circular background.
Upsell heading
Replace “Make it perfect” with: Complete your gift
Add the subtitle: Add something extra before checking out.
Category navigation
Replace the overflowing tab labels with horizontally scrollable rounded filter chips.
Initial chips: Recommended, Balloons, Bundles, Chocolate, and any other existing categories.
The selected chip should have a dark-teal filled state; inactive chips should be white with a subtle border.
No category name may be clipped. Preserve touch-friendly spacing and show a visual hint that more categories can be scrolled to.
Delivery slot
Replace the dashed container with a subtle solid pale-teal background and light border.
Format the primary line as: Delivery: Today, 9:00 AM–2:00 PM, using the customer’s actual selected date and slot dynamically.
Show the selected delivery city on a smaller second line.
Keep Change right-aligned and clearly tappable.
Sticky bottom actions
Keep the action area fixed at the bottom while the modal content scrolls.
Secondary outlined button: Continue Shopping
Primary dark-teal button: View Cart · $[current cart total]
Both buttons must meet mobile touch-target requirements.
Modal spacing and behavior
Reduce unnecessary vertical padding so the modal does not feel like a separate full page.
Keep the underlying page dimmed.
Allow the modal body/recommendations to scroll without moving the sticky bottom actions.
Respect iPhone safe areas and prevent background-page scrolling while the modal is open.


Important exclusion
Do not change the existing product recommendation cards in this task. Preserve their current imagery, proportions, prices, names, card styling, and interaction behavior. Do not add quick-add buttons.

Responsive requirements
Prioritize the mobile experience shown in the approved design.
Ensure the modal remains usable on smaller iPhones and larger mobile screens without clipped text or actions.
Maintain Presentail’s existing dark-teal, orange, serif-heading, and sans-serif UI styling.


Acceptance criteria
All approved copy is displayed accurately, with dynamic amounts, date, time slot, and city where specified.
Category chips scroll horizontally and no labels are clipped.
The delivery row uses the new compact solid style and Change opens the existing delivery-selection flow.
The bottom buttons remain visible while modal content scrolls.
Continue Shopping closes the modal and returns the customer to shopping.
View Cart opens the cart and displays the current total in its label.
Free-delivery calculations and progress remain accurate for the active country/city rules.
No product recommendation card changes are introduced.
Test on Safari iOS and Chrome mobile at common small and large viewport sizes.
