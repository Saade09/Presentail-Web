Core requirement:

Use Clerk authentication for this app and connect it to my existing Clerk instance.

User type requirement:

Create or use this TypeScript type:

type UserType = "customer" | "driver" | "team";

For this app, the user type must always be:

"userType": "customer"

Store it in Clerk publicMetadata as:

publicMetadata.userType = "customer"

Important:
Users should NOT choose their account type.
There should be no “select role,” “choose account type,” or “customer/driver/team” onboarding screen.
This is the customer gift-buying app, so the app itself assigns the user as a customer.
