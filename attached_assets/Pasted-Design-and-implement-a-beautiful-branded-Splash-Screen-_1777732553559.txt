Design and implement a beautiful branded Splash Screen for the app.

Goal:
Create a polished startup/loading screen that appears when the app first launches, before the main app/home screen loads.

Brand direction:
- The app is Presentail, focused on thoughtful gifting.
- The splash screen should feel premium, warm, elegant, and gift-focused.
- Use the existing app design language:
  - Cream/off-white background
  - Dark teal primary color
  - Soft, minimal visual style
  - Rounded, friendly elements
  - Elegant typography

Splash screen content:
- Presentail logo centered.
- Optional short tagline below the logo:
  “Gifts made personal”
- Optional subtle gift-related visual element:
  - gift box icon
  - ribbon detail
  - small sparkle accents
  - soft gradient circle behind the logo

Do not make it visually busy.
Keep it minimal, elegant, and high-end.

Animation:
Add a subtle, smooth launch animation:
- Logo gently fades in.
- Logo slightly scales from 0.95 to 1.
- Tagline fades in shortly after.
- Optional small loading indicator under the tagline.

Animation should feel premium, not playful or distracting.
Avoid heavy or long animations.

Timing:
- Splash screen should show while the app is initializing.
- Do not artificially delay the app too long.
- If app initialization is fast, keep the splash visible long enough to avoid flicker, around 800–1200ms maximum.
- After loading is complete, transition smoothly to the main app screen.

Technical requirements:
- Use the project’s existing framework and navigation setup.
- If this is Expo, use expo-splash-screen properly.
- If this is React Native bare, use the native splash screen setup or existing splash library.
- Ensure the splash screen works on both iOS and Android.
- Respect safe areas.
- Support different screen sizes.
- Avoid layout shift.
- Use existing brand assets if available.
- If no logo asset exists, use the existing text logo or app name styled consistently.

Native splash:
Also update the native launch splash configuration if applicable:
- Background color should match the app’s cream/off-white.
- Logo should be centered.
- Make sure the native splash and React splash visually match so the transition feels seamless.

App initialization:
Use the splash screen while loading:
- fonts
- stored language preference
- RTL layout setup
- auth/session state
- notification permission state if already implemented
- any other startup data

Multilingual / RTL:
The splash screen can default to English branding.
If showing the tagline from i18n, make sure it supports:
- English
- Arabic
- French

Translations:
English:
- Gifts made personal

Arabic:
- هدايا بلمسة شخصية

French:
- Des cadeaux personnalisés

RTL note:
Arabic should not break layout.
Logo remains centered.
Tagline should render correctly.

Suggested structure:
- components/SplashScreen
- hooks/useAppInitialization or similar
- Update app root/layout so the splash screen appears before navigation is ready
- Update app.json/app.config or native splash config if needed

Visual details:
- Background: cream/off-white
- Logo: dark teal
- Tagline: muted dark teal or soft gray-teal
- Loading indicator: subtle, small, dark teal or muted teal
- Optional decorative elements should be low-opacity and brand-matched

Acceptance criteria:
1. App shows a polished branded splash screen on startup.
2. Splash screen matches the app’s premium gifting style.
3. Logo is centered and visually balanced.
4. Animation is smooth and subtle.
5. Splash remains visible only while app initialization is happening.
6. No awkward white flash appears between native splash and app UI.
7. Works on iOS and Android.
8. Handles different phone screen sizes.
9. Does not break multilingual or RTL setup.
10. Main app loads normally after initialization.
