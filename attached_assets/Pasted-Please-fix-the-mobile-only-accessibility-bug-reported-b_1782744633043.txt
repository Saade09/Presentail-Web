Please fix the mobile-only accessibility bug reported by Lighthouse/PageSpeed:

Issue:
“Heading elements are not in a sequentially-descending order”
Failing element:
Product card title on mobile:
<h3 class="font-serif text-lg line-clamp-1">Nutella Cake</h3>

Problem:
On mobile, product card titles are rendered as <h3>, but the surrounding mobile page structure likely skips heading levels. For example, the page may have an <h1>, then product cards as <h3> without a visible/semantic <h2> section heading before them. This causes Lighthouse to flag the mobile page under Navigation/accessibility.

Please investigate the mobile product grid / product card component and fix heading hierarchy permanently.

Requirements:
1. Audit the mobile page heading structure only, especially category/occasion/product listing pages.
2. Make sure headings descend sequentially:
   - Page title should be <h1>
   - Main content sections should use <h2>
   - Product card titles should only be <h3> if they are inside a section that already has an <h2>
3. If the product grid does not have a real section heading on mobile, add an accessible section heading before the grid:
   - Example: <h2 className="sr-only">Products</h2>
   - This should be visually hidden but available to screen readers.
4. If product cards are not structurally inside a named <h2> section, change product card titles from <h3> to a non-heading element:
   - Prefer <p>, <div>, or <span>
   - Keep the exact same visual styling:
     className="font-serif text-lg line-clamp-1"
5. Do not create SEO issues:
   - There should still be only one <h1> per page.
   - Do not make every product title an <h2>.
   - Do not add visible headings that change the mobile UI unless needed.
6. Check both desktop and mobile rendering:
   - Desktop should not regress.
   - Mobile should pass Lighthouse heading-order audit.
7. Apply this fix globally wherever the shared ProductCard component is used, so the issue does not reappear on category, occasion, search, collection, or home product sections.
8. After the fix, test with Lighthouse/PageSpeed mobile and confirm the heading-order warning is gone.

Important:
This is not a visual bug. Please preserve the current product card design exactly. The fix should be semantic/accessibility-focused.
