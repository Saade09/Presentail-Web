  “Luxury Flower & Gift Delivery Across the GCC”

4. Validate image dimensions
Make sure every OpenGraph image used by the site is:
- 1200x630px preferred
- Minimum 600x315px
- Aspect ratio close to 1.91:1
- File size reasonable, ideally under 1MB
- Publicly accessible
- Not blocked by robots.txt, auth, cookies, or signed URLs

If existing images are vertical, square, too small, or unsuitable:
- Do not use them directly as OG images
- Place them inside a branded 1200x630 template
- Add headline and CTA
- Use safe cropping and background blur/gradient when needed

5. Improve descriptions
Ensure all page descriptions are between 110 and 160 characters where possible.

Avoid descriptions that are too short or generic.
Every page should have a clear, customer-facing description that explains what the page offers.

6. Add metadata server-side
Please ensure metadata is rendered server-side, not only client-side after hydration.

Social crawlers need to see the tags in the initial HTML response.

If this is a Next.js app:
- Use the metadata API / generateMetadata where appropriate
- Add static default metadata at the root/layout level
- Add dynamic metadata at the route level

If this is a React/Vite app:
- Add server-rendered metadata if SSR exists
- If not, implement metadata injection through the server response or routing layer
- Avoid relying only on React Helmet if crawlers cannot see the final tags

7. Add fallback logic

- Never leave og:image empty
- Never leave og:description empty
- Never use broken image URLs
