OBJECTIVE

Improve the ordering of occasions in the website navigation so the most useful and commercially important occasions appear first. The list should not be alphabetical or arbitrary. It should support city-level demand and time-sensitive seasonal merchandising.

CURRENT ISSUE

- Birthday, one of the most important and frequently purchased occasions, currently appears at the far right of the second row.
- The current sequence feels random and makes high-intent occasions harder to find.
- “Summer” is a seasonal collection rather than a true gifting occasion.

SUMMER COLLECTION

- Remove “Summer” from the Occasions navigation menu.
- Keep Summer available as a seasonal/featured collection where appropriate.
- Do not delete or deactivate the underlying collection or its products.

SORTING AND MERCHANDISING RULES

- Support a separate occasion order for each active city because demand can differ by market.
- Use the approved Beirut order above as the initial fallback/default.
- Keep the five strongest-selling occasions at the top when reliable city-level performance data is available.
- Allow an admin to manually pin an occasion to a specific position. A manual pin must take priority over demand-based ordering.
- Allow seasonal promotions to have a start date, end date, city, and desired menu position. For example, Graduation can be temporarily promoted during graduation season.
- When a scheduled promotion ends, the occasion should automatically return to its normal city-specific position.
- Do not reorder the menu during a customer session. Recalculate or publish the order on a stable schedule so the navigation does not appear to move unexpectedly.
- If there is insufficient city-level data, use the manually configured default order rather than producing a random or incomplete sequence.

ADMIN REQUIREMENTS

- Add a clear sort-order control for occasions, ideally drag-and-drop with a numeric position fallback.
- Allow configuration by country/city.
- Allow an occasion to be pinned and unpinned.
- Allow a seasonal promotion window and promoted position to be configured.
- Show whether the current position is manual, pinned, scheduled, demand-based, or inherited from the default order.
- Prevent duplicate position values from causing unstable or random ordering.

WEBSITE BEHAVIOR

- Apply the same ordering to the desktop dropdown, mobile navigation, and “View All Occasions” page unless a deliberately separate order is configured.
- Preserve the existing card design, imagery, spacing, and interaction behavior; this task is focused on ordering and classification.
- Ensure all occasion links continue to open the correct localized landing pages.
- Ensure the solution works across languages without changing the underlying sort order when labels are translated.

ANALYTICS GUIDANCE

- Track occasion impressions, clicks, click-through rate, attributed orders, and conversion rate by city.
- Only use completed/paid orders for sales-based ranking.
- Avoid double-counting products that belong to multiple occasions; use the customer’s originating occasion page/menu selection for attribution where available.

ACCEPTANCE CRITERIA

- Birthday appears first in the Beirut Occasions menu.
- The remaining Beirut occasions follow the approved default order.
- Summer no longer appears under Occasions and remains available as a seasonal collection.
- An admin can configure and save a different order per city.
- Manual pins override automated ordering.
- Scheduled promotions activate and expire correctly.
- Desktop, mobile, and View All Occasions display the intended order.
- Translations do not change the configured order.
- No broken occasion links, missing items, duplicates, or layout regressions are introduced.

QA SCENARIOS

- Test Beirut in English, Arabic, and French on desktop and mobile.
- Test a city with a custom order and a city inheriting the default order.
- Test an active seasonal promotion, an expired promotion, and a manual pin that conflicts with a scheduled position.
- Confirm that disabling an occasion removes it cleanly without corrupting the order of the remaining items.
