Create a "Frequently Bought Together" section on the product page.

Requirements:

- Only display this section when the current product belongs to either:
  - Flowers
  - Cakes

- Do not show the section for any other product categories.

Section title:
Frequently Bought Together

Behavior:
- Display products in a horizontal carousel on desktop and a swipeable carousel on mobile.
- Each product card should contain:
  - Product image
  - Product name
  - Current price
  - Quantity selector (+ / -)
  - Add button (or checkbox) to include/exclude the item

Selection:
- The main product is always included.
- Customers can optionally add any of the suggested products.
- Display a live total price for the selected items.
- Include a single button:
  "Add Selected to Cart"
- Clicking this button should add the main product and all selected recommendations to the cart in one action.

Recommendations:
- Create a new admin setting on products called "Frequently Bought Together".
- This should allow admins to manually choose multiple products to recommend.
- If no products are assigned, automatically suggest products from complementary categories:
  - Flowers:
    - Chocolates
    - Balloons
    - Teddy Bears
    - Cakes
    - Gift Cards
  - Cakes:
    - Flowers
    - Balloons
    - Chocolates
    - Teddy Bears
- Exclude unpublished, out-of-stock, or hidden products.
- Never recommend the current product itself.

Design:
- Match the existing website design.
- Use the existing product card styling where possible.
- The section should load efficiently and not noticeably impact page speed.
- Mobile layout must be fully responsive and horizontally scrollable.

Implementation:
- Reuse existing product APIs and cart APIs where possible.
- Do not duplicate business logic.
- Ensure product options (such as variations) are handled correctly before adding items to the cart.
- If a recommended product requires selecting a variation before purchase, handle this gracefully instead of failing silently.
