Objective
Improve category discoverability and tapability in Presentail’s mobile Explore menu by changing the category tiles from a 4-column grid to a 3-column grid.

Scope
Apply the new 3-column layout to the nested mobile category screens:
- Occasions
- Flowers & Plants
- Gifts

Do not change the top-level “Explore Presentail” list in this task.

Layout specifications
- Use 3 equal-width columns at mobile breakpoints.
- Outer horizontal page padding: 16px.
- Horizontal and vertical grid gap: 12px.
- Tile width: calc((100% - 24px) / 3) within the grid content area.
- Image container must remain square (1:1).
- Use the existing rounded corners, warm light-gray background, and subtle shadow.
- Keep the label centered below the image.
- Allow labels to wrap to a maximum of 2 lines.
- Reserve a consistent label area/height so rows remain aligned.
- Make the complete tile—including the image and label—one clickable target.
- Maintain a minimum effective tap target of 44px.
- Products should visually occupy approximately 65–75% of the image card.
- Normalize product scale and centering so small assets do not appear lost inside their cards.

Grid behavior
- Preserve the existing category order.
- Fill rows left to right.
- If the final row is incomplete, keep remaining items left-aligned; do not stretch or center them.
- Expected counts:
  - Flowers & Plants: 7 categories → 3 rows
  - Gifts: 7 categories → 3 rows
  - Occasions: 13 categories → 5 rows
- Keep approximately 24px between the final category row and the “View all” CTA.
- Preserve Back and Close behavior and the existing header hierarchy.
- Preserve the user’s submenu state when navigating Back.

Copy
Standardize CTA labels as:
- “Shop all Flowers & Plants”
- “Shop all Gifts”
- “View all Occasions”

Use existing category names and fix these labels where applicable:
- “Luxury Arrangements” instead of “Lux Arrangements”
- “Hand-Tied Bouquets” instead of “Hand Bouquets”

Responsive requirements
- Apply the 3-column grid to supported mobile widths.
- Ensure no horizontal scrolling.
- Verify long labels at narrow widths, including:
  - Congratulations
  - Preserved Flowers
  - Love & Romance
  - Luxury Arrangements
- Do not truncate category names with ellipses.
- Tablet/desktop behavior should remain unchanged unless the existing component shares the same mobile breakpoint logic.

Acceptance criteria
- All three nested category screens render exactly 3 columns on mobile.
- Tiles are equal width and image containers are square.
- Product assets are consistently centered and visually scaled.
- Labels remain legible, wrap to no more than 2 lines, and rows stay aligned.
- Entire tile + label areas are clickable.
- Category order and navigation destinations are unchanged.
- Incomplete final rows remain left-aligned.
- CTA spacing and updated copy match the specification.
- No overflow, clipping, layout shift, or horizontal scroll.
- Verified on iPhone SE/narrow viewport, standard iPhone viewport, and a large mobile viewport.
- Back and Close controls continue to work correctly.
- Existing analytics events for category selection and “View/Shop all” continue firing.

QA checklist
- Compare implementation with the approved 3-column Occasions mockup from the product discussion.
- Test every category link on Occasions, Flowers & Plants, and Gifts.
- Confirm visual balance for unusually tall, wide, and small product cutouts.
- Test labels at default and increased browser text size.
- Confirm no regression to loading states or image aspect ratios.

Deliverable
Production-ready responsive implementation plus screenshots of all three updated screens at a standard iPhone viewport.
