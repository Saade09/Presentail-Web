We need to SEO-optimize the entire Presentail customer website using a scalable dynamic SEO system, not by manually editing every page.

Please create a centralized SEO metadata system that generates SEO tags based on the current page type, city, country, language, category, occasion, product, and brand.

The website has pages like:
- Homepage
- City homepage
- Category pages, for example /en-lb/beirut/category/plants
- Product pages
- Occasion pages
- Search pages
- Account pages
- Checkout pages
- Static pages like About, Contact, FAQ, Terms, Privacy

SEO requirements:

1. Every public indexable page should have:
- <title>
- <meta name="description">
- canonical URL
- Open Graph title
- Open Graph description
- Open Graph image
- Twitter title
- Twitter description
- Twitter image
- hreflang tags for English, Arabic, and French if available
- robots meta tag

2. Metadata must be server-rendered or included in the initial HTML source.
Do not rely only on client-side JavaScript after page load.

3. Create reusable SEO templates by page type.

Homepage SEO:
Title:
Online Flower & Gift Delivery | Presentail | Express Delivery

Description:
Send flowers, cakes, balloons, plants, chocolates and more gifts online with Presentail. Express same-day delivery available in Lebanon, UAE, and Cyprus.

City homepage SEO:
Title format:
Flower & Gift Delivery in {City} | Presentail

Description format:
Send flowers, cakes, balloons, plants, chocolates and gifts online in {City}. Express same-day delivery available with Presentail.

Category page SEO:
Title format:
{Category} Delivery in {City} | Presentail

Description format:
Shop {category} online in {City}. Send beautiful {category} with Presentail and enjoy express same-day delivery.

Examples:
Plants Delivery in Beirut | Presentail
Flower Bouquets Delivery in Dubai | Presentail
Cakes Delivery in Beirut | Presentail

Occasion page SEO:
Title format:
{Occasion} Flowers & Gifts in {City} | Presentail

Description format:
Send {occasion} flowers, cakes, balloons and gifts in {City}. Order online with Presentail for express same-day delivery.

Examples:
Birthday Flowers & Gifts in Beirut | Presentail
Anniversary Flowers & Gifts in Dubai | Presentail

Product page SEO:
Title format:
{Product Name} Delivery in {City} | Presentail

Description format:
Order {Product Name} online in {City}. Send it with Presentail for fast, reliable gift delivery.

If the product has a short description, use it in the meta description while keeping the description under 160 characters.

4. Add structured data:
- Organization schema for Presentail
- Website schema for the homepage
- LocalBusiness schema where relevant
- Product schema for product pages
- BreadcrumbList schema for category, occasion, and product pages
- ItemList schema for category and occasion listing pages

5. Add correct canonical URLs:
- Each page should point to its clean final URL
- Avoid duplicate canonicals caused by filters, sort, query parameters, or tracking parameters
- Category sort/filter pages should usually canonicalize back to the main category page unless they are intended to rank

6. Handle robots rules:
- Public pages should be index, follow
- Checkout, cart, account, login, search result pages, and internal pages should be noindex, follow
- Empty category pages should be noindex until they contain products

7. Add breadcrumbs in structured data even if visual breadcrumbs are light or hidden on mobile.

8. Add image SEO:
- Product images should have descriptive alt text
- Category images should have descriptive alt text
- Open Graph image should use a high-quality Presentail image or page-relevant image

9. Add multilingual SEO:
- Generate hreflang links for English, Arabic, and French versions of the same page
- Include x-default where appropriate
- Make sure translated pages have translated title and description, not only the same English metadata

10. Add sitemap support:
- Generate or update sitemap.xml dynamically
- Include homepage, city pages, category pages, occasion pages, product pages, and important static pages
- Exclude cart, checkout, account, login, admin, and filtered URLs
- Add lastmod where available

11. Add robots.txt:
- Allow public pages
- Disallow cart, checkout, account, login, admin, and internal API routes
- Reference sitemap.xml

12. Please create a clean SEO helper/module so we can easily update templates later.

- A product page
