We ran an SEO audit for presentail.com and found several major SEO issues that need to be fixed now and prevented in the future.

Audit files/issues:

1. seo_non_friendly_url.csv

   * 827 URLs marked as not SEO-friendly

2. title_tag_too_short.csv

   * 444 pages have title tags that are too short

3. duplicate_meta_descriptions.csv

   * 1,221 pages have duplicate meta descriptions

4. duplicate_title_tags.csv

   * 1,221 pages have duplicate title tags

The goal is not only to patch the current URLs manually. Please fix the SEO system so future pages automatically generate unique, strong, SEO-friendly titles, meta descriptions, canonicals, URLs, and index/noindex rules.

Important context:
The site has multilingual and city-based URLs such as:

* /en-lb/beirut
* /ar-ae/abu-dhabi
* /fr-cy/nicosia
* /en-lb/beirut/product/15-red-roses-arrangement
* /en-lb/beirut/category/plants
* /en-lb/beirut/occasion/birthday
* /en-lb/beirut/faqs
* /en-lb/beirut/careers
* /en-lb/beirut/contact
* /en-lb/beirut/privacy
* /en-lb/beirut/terms

The audit shows many duplicates because static pages like blog, careers, contact, corporate, FAQs, partner, privacy, terms, and weddings are repeated across many cities and languages with the same title and description.

Please investigate and fix the following:

4. Fix non-SEO-friendly URLs

The audit found 827 URLs marked as not SEO-friendly.

Please investigate why these URLs were flagged.

Likely issues to check:

* trailing slash duplicates
* city duplicates for static pages
* URLs that are too generic
* URLs that create duplicate content
* pages available with and without trailing slash
* pages using plural or unclear slugs inconsistently
* static pages repeated under every city when they do not need to be city-specific

Important URL rules:

* Use lowercase slugs only.
* Use hyphens, not spaces or underscores.
* Avoid duplicate trailing slash versions.
* Choose either trailing slash or no trailing slash and enforce it globally.
* Redirect the non-preferred version with a 301 redirect.
* Avoid query parameters in indexable URLs.
* Avoid duplicate URLs for the same content.
* Product/category/occasion URLs should be descriptive.

Recommended clean URL examples:

* /en-lb/beirut
* /en-lb/beirut/category/plants
* /en-lb/beirut/occasion/birthday
* /en-lb/beirut/product/15-red-roses-arrangement
* /en-lb/beirut/contact
* /en-lb/beirut/faqs

5. Decide which city-specific static pages should be indexed

The audit strongly suggests that static pages are duplicated across many cities.

Please classify static pages into one of two groups:

Group A: City-specific and indexable if content is unique

* Contact
* FAQs
* Corporate gifting
* Weddings

These can be city-specific only if the page title, description, H1, body content, canonical, and structured data mention the city and provide city-relevant content.

Group B: Not city-specific and should not create indexable duplicates

* Privacy Policy
* Terms of Use
* Careers
* Partner page
* Blog index if the content is identical

For Group B:
Either:

* use one canonical URL per language, for example /en/privacy, /ar/privacy, /fr/privacy
  or:
* keep city URLs accessible but add noindex and canonical to the main language version.

Do not allow dozens of identical Privacy, Terms, Careers, Partner, or Blog pages to be indexed for every city.

6. Canonical rules

Please enforce canonical URLs consistently.

Rules:

* Each page should have one clean canonical URL.
* The canonical should match the preferred non-trailing-slash or trailing-slash policy.
* Duplicate trailing slash pages should redirect or canonicalize to the preferred version.
* Filtered and sorted category pages should canonicalize back to the clean category page unless we intentionally want them indexed.
* Static duplicate pages should canonicalize to the main version if content is identical.
* Product pages should canonicalize to their clean product URL.
* City/category/occasion pages should canonicalize to their exact clean URL.

Examples:
https://presentail.com/en-lb/beirut/
should 301 redirect or canonicalize to:
https://presentail.com/en-lb/beirut

https://presentail.com/en-lb/beirut/category/plants?sort=featured
should canonicalize to:
https://presentail.com/en-lb/beirut/category/plants

7. Index/noindex rules

Please make sure only valuable public pages are indexable.

Index:

* Homepage
* City homepages
* Category pages with products
* Occasion pages with products
* Product pages
* City-specific content pages only if content is unique and useful

Noindex:

* Cart
* Checkout
* Login
* Register
* Account
* Profile
* Orders
* Payment success/failure pages
* Search result pages
* Empty category pages
* Empty occasion pages
* Filtered/sorted pages
* Duplicate static city pages
* Duplicate trailing slash pages if not redirected
* Any thin page with no unique content

11. Multilingual SEO

Please make sure English, Arabic, and French pages have translated metadata.

Rules:

* Do not use the exact same English metadata on Arabic and French pages.
* If product names are not translated, keep the product name as-is but translate the surrounding SEO phrase.
* hreflang alternates should point to equivalent pages in each language where available.
* Include x-default where appropriate.
* Canonicals should be self-referencing within each language, not all pointing to English unless the page is intentionally not translated.
