* Top function call: `/assets/vendor-re....js:9:103040`

### Likely problem area

The source points to a mobile-detection script/hook. If we currently calculate mobile state using `window.innerWidth` or manual resize listeners, replace this with a safer `matchMedia`-based implementation.

Preferred approach:

```ts
import { useEffect, useState } from "react";

const MOBILE_BREAKPOINT = 768;

export function useIsMobile() {
  const [isMobile, setIsMobile] = useState<boolean>(() => {
    if (typeof window === "undefined") return false;
    return window.matchMedia(`(max-width: ${MOBILE_BREAKPOINT - 1}px)`).matches;
  });

  useEffect(() => {
    if (typeof window === "undefined") return;

    const mediaQuery = window.matchMedia(`(max-width: ${MOBILE_BREAKPOINT - 1}px)`);

    const handleChange = (event: MediaQueryListEvent) => {
      setIsMobile(event.matches);
    };

    setIsMobile(mediaQuery.matches);

    if (mediaQuery.addEventListener) {
      mediaQuery.addEventListener("change", handleChange);
      return () => mediaQuery.removeEventListener("change", handleChange);
    }

    mediaQuery.addListener(handleChange);
    return () => mediaQuery.removeListener(handleChange);
  }, []);

  return isMobile;
}
```

Avoid resize listeners that constantly read `window.innerWidth` and cause rerenders.

### Required fixes

Please implement the following:

1. Replace mobile detection based on continuous resize measurement with `matchMedia`.
2. Debounce or throttle any remaining resize/scroll listeners.
3. Avoid reading layout properties immediately after writing DOM styles/classes.
4. Batch DOM reads before DOM writes.
5. Move expensive layout reads into `requestAnimationFrame` where needed.
6. Avoid unnecessary `useLayoutEffect` unless layout must be measured before paint.
7. Memoize mobile/header/cart state where possible so resize changes do not rerender the entire page.
8. Make sure event listeners are cleaned up properly.
9. Check if any third-party library is triggered by our code unnecessarily on load or resize.
