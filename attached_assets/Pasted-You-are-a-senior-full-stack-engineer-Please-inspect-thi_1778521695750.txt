You are a senior full-stack engineer. Please inspect this app end-to-end and optimize it without changing the core functionality or user experience.

Goal:
Improve performance, reliability, code quality, security, and maintainability.

Please do the following:

1. First, analyze the codebase before editing anything.
   - Identify the tech stack, app structure, main entry points, database usage, API routes, frontend pages/components, and build/deploy setup.
   - Find performance bottlenecks, unnecessary re-renders, slow database queries, duplicated code, large dependencies, blocking operations, and inefficient API calls.

2. Optimize the app safely.
   - Improve frontend load speed and responsiveness.
   - Reduce unnecessary JavaScript, repeated API calls, and expensive renders.
   - Add loading/error states where missing.
   - Optimize backend routes, database queries, caching, and validation.
   - Remove dead code, unused imports, duplicated logic, and unnecessary dependencies.
   - Improve environment variable handling and avoid exposing secrets.
   - Strengthen security around auth, input validation, rate limits, file uploads, and API endpoints.
   - Improve error handling and logging without adding noisy logs.

3. Preserve existing behavior.
   - Do not remove features.
   - Do not redesign the app unless there is a clear performance or usability reason.
   - Do not introduce major new dependencies unless absolutely necessary.
   - If a change is risky, explain it first and choose the safer option.

4. Test everything.
   - Run the app.
   - Run existing tests, linting, type checks, and build commands if available.
   - Fix any errors caused by the optimization.
   - Verify the main user flows still work.

5. At the end, give me a clear report with:
   - What you found.
   - What you changed.
   - Why each change improves the app.
   - Any remaining issues or recommended next steps.
   - Commands I should run to test or deploy.

Optimization priorities:
1. Faster page load and smoother user experience.
2. Fewer bugs and runtime errors.
3. Cleaner, easier-to-maintain code.
4. Better security and production readiness.
5. No unnecessary rewrites.

Start by auditing the codebase and then implement the highest-impact safe improvements.
