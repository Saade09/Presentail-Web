Please implement Google Ads and UTM attribution capture in the customer-facing Presentail App.

Important context:
This is the customer-facing app where customers browse products, add to cart, checkout, and place orders. This is where Google Ads traffic lands, so attribution must be captured here before the order is created.

Goal:
Capture marketing attribution data from the customer’s visit and attach it to the order creation payload.

Please capture these URL parameters when available:

* gclid
* gbraid
* wbraid
* utm_source
* utm_medium
* utm_campaign
* utm_id
* utm_term
* utm_content

Also capture:

* referrer
* first landing page URL
* first landing page path
* last landing page URL
* last landing page path
* captured timestamp
* selected city/country if available
* conversion timestamp when order is placed

Please store both:

1. first_touch attribution
2. last_touch attribution

Rules:

* first_touch should be saved once and not overwritten.
* last_touch should update whenever a new marketing parameter is detected.
* Attribution should persist across browsing, cart, and checkout using first-party cookie or localStorage.
* Use a reasonable expiration, such as 90 days.
* If localStorage/cookies are blocked, checkout should still work.
* Attribution capture must never block order placement.

When an order is created, include an attribution object in the order creation request.
