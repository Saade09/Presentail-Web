Objective

Add a short contextual description beneath the title on every category and occasion page. The description must explain what customers can purchase, communicate verified delivery availability and dynamically reference the customer’s selected delivery area.

Approved example

“Birthday flowers, cakes and gifts available for same-day delivery in Beirut.”

“Beirut” is dynamic. Presentail serves more than 35 delivery areas, and the correct localized delivery-area name must appear based on the current page context.

Placement and design

- Display directly below the page title and product count.
- Display above recipient filters or the product-filtering interface.
- Align with the left edge of the page title.
- Use 16px medium-grey sans-serif text.
- Limit the text to approximately 600px width.
- Keep it to one line where possible and no more than two lines on mobile.
- Use a standard paragraph element; the page title remains the H1.
- Preserve the existing category/occasion layout and spacing.

Page combinations

Generate and store a description for each combination of:

- Page type: Category or Occasion
- Category or occasion ID
- Delivery-area ID
- Language: English, Arabic or French

Do not hard-code Beirut or any other delivery area.

Generation architecture

Do not generate text whenever a customer visits the page. Generate it when the relevant page combination is created or updated, store the result in the database and render the stored copy server-side.

Generate or regenerate when:

- A category or occasion is created or published.
- A page becomes available in a new delivery area.
- The category or occasion name changes.
- Relevant product or delivery availability changes.
- A new language is enabled.
- An administrator explicitly selects Regenerate.

AI input

Provide structured, verified data:

- page_type: category or occasion
- page_name
- delivery_area_name
- country_name
- language
- available_product_types
- same_day_delivery_available
- brand_name: Presentail

Use localized page and delivery-area names for the requested language. The AI must not invent product types, delivery promises or unsupported claims.

AI prompt

You are writing concise contextual copy for a premium flower and gift delivery website.

Write one natural sentence describing the supplied category or occasion page.

Inputs:
- Page type: {{page_type}}
- Page name: {{page_name}}
- Delivery area: {{delivery_area_name}}
- Country: {{country_name}}
- Available product types: {{available_product_types}}
- Same-day delivery available: {{same_day_delivery_available}}
- Language: {{language}}

Rules:
- Write exactly one concise sentence.
- Mention the page topic naturally.
- Mention the delivery area exactly once.
- Mention same-day delivery only when same_day_delivery_available is true.
- Only mention product types supplied in the input.
- Write naturally in the requested language.
- Keep the description below 150 characters where practical.
- Do not use emojis, exclamation marks, quotation marks, headings or markdown.
- Do not use unsupported superlatives or claims.
- Do not include a call to action.
- Return only the final sentence.

Existing pages

Create a queued background job to generate descriptions for all existing combinations of:

- Categories
- Occasions
- Active delivery areas
- English, Arabic and French

Include retry handling, failure logging and generation-status tracking. Never block a customer page request while waiting for AI generation.

Admin controls

Add the following controls to the category and occasion administration pages:

- Generated contextual description
- Edit action
- Regenerate action
- Generation status
- Last-generated date
- Manual-override indicator

A manually edited description must not be overwritten automatically. Only an explicit administrator action may replace a manual override.

Fallback copy

If generation fails or stored copy is unavailable, use a deterministic fallback.

Occasion:
“{{occasion_name}} flowers and gifts available for delivery in {{delivery_area_name}}.”

Category:
“Shop {{category_name}} available for delivery in {{delivery_area_name}}.”

Add “same-day” only when confirmed by delivery configuration.

Acceptance criteria

- Every category and occasion page displays a contextual description.
- The selected delivery-area name appears dynamically and is never hard-coded.
- Descriptions are available in English, Arabic and French.
- Only verified product types and delivery promises are mentioned.
- Generated descriptions are stored and rendered server-side.
- No AI generation occurs during normal customer page loads.
- A safe fallback appears when generation fails.
- Administrators can edit and regenerate descriptions.
- Manual overrides are protected from automatic replacement.
- Existing combinations are generated through a controlled background job.
- Copy displays correctly on desktop and mobile without disrupting the existing layout.
