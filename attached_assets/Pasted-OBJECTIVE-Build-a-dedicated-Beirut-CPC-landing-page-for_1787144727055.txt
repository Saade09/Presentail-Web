Build a dedicated Beirut CPC landing page for high-intent searches around late-night and last-minute flower delivery. The page must make the 11:30 PM Beirut-time cutoff unmistakable, show only inventory that can genuinely be delivered late tonight, and preserve Presentail’s premium brand experience.

TARGET MARKET

Beirut, Lebanon only.

SUGGESTED URL

/en-lb/beirut/late-night-flower-delivery

Confirm the final slug and indexing/canonical strategy before launch so this page does not unintentionally compete with the main Beirut flower-delivery page.

CUTOFF AND TIMEZONE LOGIC

- Use the IANA timezone “Asia/Beirut”; do not use a fixed UTC offset
- Respect Beirut daylight-saving changes automatically
- Before 11:30 PM Beirut time: show the late-night promise and eligible inventory
- At and after 11:30 PM Beirut time: immediately stop promising delivery tonight
- After cutoff, replace the status/CTA with truthful next-available-delivery messaging and remove or relabel late-night eligibility
- Define the exact fallback CTA and next-available date from the existing delivery-slot system
- Ensure cached pages/CDN behavior cannot leave the pre-cutoff promise visible after 11:30 PM
- If operations closes late-night delivery early, inventory and messaging must update without a code release

INVENTORY RULES

- Source products from real Beirut inventory
- Filter for in-stock and late-night eligible products only
- Products that sell out must disappear or show an accurate unavailable state
- Never show a late-night badge based only on static merchandising
- Empty-state behavior must be designed: if no products remain, direct users to the next available delivery window or support agent

PAID-SEARCH AND ANALYTICS

- Preserve GCLID, UTM parameters, and attribution throughout the shopping journey
- Confirm events for:
  - primary CTA click
  - support-agent click
  - product click
  - add to cart
  - checkout start
  - purchase
- Make the page distinguishable in analytics from the main Beirut flower-delivery landing page
- Verify Google Ads conversion attribution after deployment

RESPONSIVE / PERFORMANCE / ACCESSIBILITY

- Add a sticky mobile CTA if consistent with the current ecommerce framework
