SCOPE: MOBILE CHECKOUT ONLY

Implement the final approved mobile checkout redesign shown in the generated mockup.

This task is explicitly limited to mobile checkout. Do not change the desktop checkout experience as part of this task. Desktop has a separate implementation task.

OBJECTIVE

Shorten the mobile Delivery Details step, keep the selected arrival promise visible even when Order Summary is collapsed, reduce form friction, and strengthen the payment handoff.

Implement exactly these approved improvements:

1. Improve the collapsed Order Summary.
2. Replace the large Delivery Time section with a compact delivery confirmation.
3. Compress Sender Details.
4. Reduce Recipient Details height.
5. Stack First Name and Last Name as separate full-width rows.
6. Strengthen the sticky footer.

1. Checkout header and two-step progress.

Do not change this order.
