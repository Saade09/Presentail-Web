PART 7: METRIC CALCULATIONS

Click-through rate:

click_through_rate =
product_card_clicks / product_card_impressions

Website conversion rate:

conversion_rate =
confirmed_purchases / product_page_views

Add-to-cart rate:

add_to_cart_rate =
add_to_cart_events / product_page_views

Refund rate:

refund_rate =
refunded_orders / completed_orders

Cancellation rate:

cancellation_rate =
cancelled_orders / total_orders

Gross profit:

gross_profit =
revenue - cost_of_goods_sold

Gross margin percentage:

gross_margin_percentage =
gross_profit / revenue

Protect every calculation against division by zero.

Use smoothed rates to prevent products with tiny sample sizes from ranking first.

Example smoothed conversion rate:

smoothed_conversion_rate =
(
    product_purchases
    + category_average_conversion_rate * minimum_sample_size
)
/
(
    product_views
    + minimum_sample_size
)

Use a minimum sample size between 30 and 100. Start with 50.

Apply similar smoothing to click-through rate, add-to-cart rate, refund rate, and cancellation rate.

PART 8: NORMALIZATION

Normalize ranking metrics to a value between 0 and 1 before applying weights.

Use percentile-based or logarithmic normalization for metrics such as:

- Sales
- Revenue
- Gross profit
- Clicks
- Impressions
- Unique customers

This prevents one unusually large product from dominating the ranking.

Example:

normalized_sales =
log(1 + product_sales_30d) /
log(1 + maximum_sales_30d)

Calculate comparison values within a relevant product group or section where possible.
