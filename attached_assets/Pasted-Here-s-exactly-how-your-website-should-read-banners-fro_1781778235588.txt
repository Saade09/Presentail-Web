Here's exactly how your website should read banners from Presentail OS to render them on the homepage. There's already a public, no-auth endpoint built for this.

The endpoint to call
GET /api/storefront/homepage-banners?countryCode=LB&cityId=12&device=desktop

Query parameters:

countryCode (required) — ISO country code of the visitor, e.g. LB, AE, CY
cityId (optional) — the visitor's city ID. Banners targeted to specific cities only match when you pass this; "show in all cities" banners match regardless.
device (required) — desktop or mobile. The server returns the media/link for that side only, so call it once per layout (or detect device and pick one).
No API key or login needed. The workspace is locked server-side, so you only ever get your own banners. The server already handles all the filtering for you: it only returns banners that are active, enabled for that device, match the country (and city), and fall within their scheduled start/end window.

What you get back
{
  "banners": [
    {
      "id": 1,
      "internal_name": "Summer 26",
      "title": "Big Savings",
      "headline": "Up to 50% Off",
      "subtitle": "On all beachwear",
      "cta_text": "Shop now",
      "device": "desktop",
      "media_type": "image",
      "media_url": "/objects/user_.../uploads/87f1f8c7-...",
      "fallback_image_url": null,
      "link_url": "https://new.presentail.com/en-lb/beirut/catego...",
      "sort_order": 0,
      "priority": 1
    }
  ]
}

How to map each field to your homepage (matching your Edit Banner screenshot)
Banner field on website	Comes from	Notes
Title	title	May be empty — hide the element if blank
Headline	headline	The big text; may be empty
Subtitle	subtitle	Smaller descriptive text; may be empty
CTA button label	cta_text	e.g. "Shop now". If empty, hide the button
CTA / click destination	link_url	Where the banner (and CTA) links to
Image / video source	media_url	Render <img> if media_type === "image", <video> if "video"
Video poster / fallback	fallback_image_url	Only set for videos; use as the poster image
internal_name	internal_name	Admin label only — don't show to customers
Important details:

Every text field except CTA can be empty ("" or null) — render conditionally so you don't show empty headings.
Ordering: sort by sort_order first, then priority (both ascending) to control which banner shows first in your carousel/hero.
Media URLs are relative paths like /objects/... — prefix them with your OS API origin to load them (e.g. https://your-os-domain/api/objects/...). They're served publicly through the storage proxy.
Video banners carry both media_url (the video) and fallback_image_url (poster). For images, fallback_image_url is null.
So a minimal homepage flow is: detect the visitor's country (and ideally city), call the endpoint once with device=desktop and once with device=mobile, then loop the returned banners array rendering media + title/headline/subtitle + CTA, linking everything to link_url.
